# CI Notes

During `npm run build`, you may see the following:

Browserslist: browsers data (caniuse-lite) is 7 months old. Please run:
  npx update-browserslist-db@latest

This is an informational notice and does not indicate a failure in our CI pipeline.
It is safe to ignore in CI environments with restricted network access.

If you wish to update locally, you can run:
  npx update-browserslist-db@latest
